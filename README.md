# APK Analyzer

1. Secret add karo: Settings -> Secrets and variables -> Actions -> `GEMINI_API_KEY`
2. APK daalo: (a) chhota ho to `apk/` folder me, ya (b) bada ho to Releases me naya release banake APK attach karo
3. `changes.txt` me likho kya karna hai
4. Actions -> APK Analyze -> Run workflow

Result: repo ke `results/` folder me report, aur Artifacts me full source (`apk-analysis`).
Sirf apni ya permission wali APK analyze karo.
